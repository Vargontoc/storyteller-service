# Storyteller Agent App

## Description

Aplicación ligera que genera cuentos infantiles, en esta versión (v. 1.0) para niños de 3 a 4 años.

## API

Capa backend donde reside la lógica de negocio y la comunicación con el agente para la generación de cuentos

## App

Aplicación donde reside la lógica de la aplicación visual. Se rquiere tener levantada la AOU.
